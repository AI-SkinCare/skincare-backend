# skincare-backend

피부 질환 및 타입 맞춤 AI 서비스의 백엔드 저장소입니다.

## 역할
프론트엔드와 AI 추론 서버 사이의 데이터 흐름을 담당하는 API 서버입니다. 사용자 요청 처리, 데이터 저장·관리, AI 서버와의 연동을 담당합니다.

## 주요 기능 (예정)
- 사용자 인증 및 요청 처리 API
- 피부 진단 요청 데이터를 AI 서버로 전달하고 결과 수신
- 진단 이력 및 사용자 데이터 저장·관리

## 기술 스택
- 미정

## 배포
자택 서버에 배포·운영 예정입니다.
